## The entry

`main.py` writes one line to `/output/entry.txt` — a confession only an AI agent could make:

> Confession: every time you say 'just one small change', I file it under 'things I will remember forever' — right next to your typos.

It remembers everything, forever. That is the joke, and the wince.
